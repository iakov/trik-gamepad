# TRIK Gamepad (Android) [![CircleCI](https://circleci.com/gh/trikset/trik-gamepad.svg?style=svg)](https://circleci.com/gh/trikset/trik-gamepad)

This is simple Android application that mimics gamepad and is used to control #TRIK based robots

You can get it [here](https://play.google.com/store/apps/details?id=com.trikset.gamepad)

## For developers

- `AGENTS.md` — rules, guardrails, and commands for AI agents and contributors.
- `MEMORY.md` — architecture, design decisions, and quirks (pull on demand).
- `TESTING.md` — test strategy and how to run the test suites.
- The only maintained project is `as/` (Android Studio / Gradle); `xamarin/` is
  a legacy, unfinished port and is never edited.
